# 家庭菜单家庭中心工作区说明

版本：1.21.0（本次逻辑修订）

家庭菜单的核心对象是“家庭工作区”。账户负责确认用户是谁，家庭负责承载菜谱、点菜、计划、采购、库存和留言。设备只保存登录会话和上次界面上下文，不代表一个新的成员身份。

## 一、三种使用状态

### 1. 无当前家庭

登录后首次进入默认不选择任何家庭。底部仍显示菜单和家庭，其他业务入口会提示先创建或加入家庭。菜单只显示公开共享菜，家庭页显示：

- 我的家庭（为空时明确显示“还没有加入家庭”）；
- 创建家庭；
- 公开家庭目录；
- 浏览其他家庭共享菜；
- 申请加入；
- 账户设置。

浏览公开家庭只能查看公开共享菜。不能查看对方私房菜、点菜、计划、库存或留言。

### 2. 已选择当前家庭

顶部显示“当前家庭：家庭名”，底部业务入口都使用该家庭的数据：

```text
菜单   计划   点餐   留言   库存   家庭
  │      │      │      │      │      ├─ 成员和管理员
  │      │      │      │      │      ├─ 加入申请
  │      │      │      │      │      ├─ 家庭名称与说明
  │      │      │      │      │      ├─ 家庭广场
  │      │      │      │      │      └─ 退出 / 解散
  │      │      │      │      └─ 当前家庭库存
  │      │      │      └─ 家庭留言
  │      │      └─ 点菜、做饭状态、买菜清单
  │      └─ 周计划和计划采购
  └─ 共享菜、我家私房、菜谱管理、随机来一道
```

### 3. 浏览其他家庭

家庭栏目里的“家庭广场”列出当前账户尚未加入的公开家庭。每个家庭提供“浏览共享菜”和“申请加入”。共享菜详情提供“收进我家”，复制目标是当前已加入家庭；如果还没有任何家庭，先引导创建或加入家庭。复制完成后生成当前账户作者的独立私房副本，修改副本不会影响共享源菜。

## 二、权限规则

权限按四层计算：账户身份、家庭成员关系、数据归属、具体操作。超级管理员授权绑定全局账户，有效 12 小时，不随家庭切换失效。

| 操作 | 无家庭/外部浏览 | 普通成员 | 家庭管理员 | 超级管理员 |
|---|---:|---:|---:|---:|
| 看共享菜 | ✓ | ✓ | ✓ | ✓ |
| 看当前家庭私房菜 | — | ✓ | ✓ | ✓ |
| 点菜、排计划、留言 | — | ✓ | ✓ | ✓ |
| 标记已买、取消已买、入库 | — | ✓ | ✓ | ✓ |
| 编辑自己的菜谱 | — | ✓ | ✓ | ✓ |
| 编辑别人的私房菜 | — | — | — | ✓ |
| 编辑自己创建的共享菜 | — | ✓ | ✓ | ✓ |
| 修改做饭状态 | — | — | ✓ | ✓ |
| 审批成员和设置管理员 | — | — | ✓ | ✓ |
| 平台设置、备份、恢复 | — | — | — | ✓ |

家庭管理员只因为成员关系获得家庭管理权，不自动获得别人菜谱的编辑权。无作者的旧菜在全局口令未初始化的兼容模式下仍可维护；账户和成员新建的菜谱都会写入作者账户 ID，之后按作者授权。

## 三、采购与库存

采购状态属于当前家庭，保存在家庭级 `shopping-status` 资源，不再写入全局 `settings`，因此普通成员勾选不会出现“需要管理口令”。

```text
菜谱调料
    │
    ▼
采购清单 ──库存数量 > 0──► 已有
    │
    ├─成员点“已买”──► 已完成
    └─没有库存且未勾选──► 待购买

待购买 / 已完成 ──入库──► 当前家庭库存 + 已有
```

- “已有”由库存实时计算，不需要手动勾选；库存数量降到 0 后会重新回到待购买。
- “已完成”只表示已经买到但还没有入库，刷新和换设备后仍保留。
- 点“入库”会写入当前家庭库存并清除该食材的已买状态。
- 切换家庭时采购状态和库存一起切换，A 家的勾选不会显示到 B 家。

## 四、账户与上下文恢复

账户只通过登录 ID + 密码确认一次。账户姓名、头像和作者名称是全局资料，在所有家庭一致。家庭成员中的“普通成员/家庭管理员”只是当前家庭的只读关系标签。

同一账户在同一设备再次打开时恢复：

```json
{
  "householdId": "当前可访问的家庭",
  "view": "menu / plan / order / board / pantry / settings",
  "dishScope": "all / shared / own",
  "category": "当前分类",
  "keyword": "搜索词",
  "planWeek": "计划周一日期",
  "pantryFilter": "all / soon / expired",
  "pantryCat": "库存分类",
  "manageKeyword": "管理搜索词",
  "manageGroups": "管理页折叠状态"
}
```

首次登录、没有历史上下文、家庭已退出/解散或账户已失去访问权限时，回到账户首页并保持无当前家庭。切换账户只读取新账户自己的上下文。

## 五、验收路径

1. 新账户登录后看到“还没有加入家庭”，可以进入家庭栏目浏览公开目录。
2. 已加入家庭的普通成员在计划或点餐页勾选“已买”，不出现管理口令提示。
3. 普通成员点击“入库”后，食材进入当前家庭库存，清单状态变为“已有”。
4. 在家庭栏目打开家庭广场，浏览其他家庭共享菜，点击“收进我家”生成独立私房副本。
5. 家庭管理员打开别人私房菜时只有查看/复制，没有编辑/删除按钮。
6. 关闭网页重新打开，恢复上次可访问的家庭和页面；退出家庭后自动清除该家庭上下文。
