# 零库存清理与花生分类设计

## 目标

数量型库存用完后立即从库存中移除，不留下 `0 g`、`0 个` 等无库存记录。将做菜使用的花生原料归到豆制品分类，同时让零食类花生保持原分类。

## 规则

- 家庭管理员完成计划菜并扣减库存时，数量型库存行减至 0 即删除；库存不足提示仍保留，表示实际需求超过了已有库存。
- 手动保存数量为 0 时，已有数量型库存行删除；新建 0 数量条目不创建。
- 服务启动时清除历史数量型库存中数量为 0 的记录。`presence` 型记录以 `hasStock` 表示状态，允许其规范化字段中的数量为 0。
- 预置名称“花生”归入现有“豆制品”分类；“花生米”“油酥花生米”等做菜原料继续归入豆制品；已有“花生零食”及零食分类不改变。

## 验收

- 计划扣减恰好用完库存后，状态接口和持久化数据中都没有该库存行。
- 手动编辑库存为 0 后，该行被删除；新建 0 数量库存不产生记录。
- 服务启动迁移会清理旧的数量型零库存行，但保留 `presence` 型状态。
- 预置“花生”分类为豆制品；其他零食预置分类不变。
